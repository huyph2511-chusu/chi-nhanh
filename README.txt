CHI NHANH PWA 1.0

1. Tải và giải nén toàn bộ thư mục.
2. Đăng tải nguyên thư mục lên một dịch vụ lưu trữ web tĩnh có HTTPS, ví dụ Netlify Drop hoặc GitHub Pages. Đảm bảo index.html nằm ở gốc website.
3. Mở URL HTTPS được cấp bằng Safari trên iPhone.
4. Chọn Chia sẻ (Share) > Thêm vào Màn hình chính (Add to Home Screen) > Thêm.
5. Mở biểu tượng Chi Nhanh trên màn hình chính.

Lưu ý: Không thể cài PWA trực tiếp từ tệp ZIP hoặc đường dẫn file:// trên iPhone. Cần có URL HTTPS trước.
Dữ liệu lưu cục bộ trên trình duyệt/web app của thiết bị, KHÔNG tự đồng bộ iCloud. Safari có thể xóa dữ liệu website trong một số tình huống; hãy dùng Cài đặt > Sao lưu JSON thường xuyên, lưu tệp trong Files/iCloud Drive. Không dùng chế độ duyệt riêng tư.
Để cập nhật ứng dụng, tải phiên bản mới lên cùng URL và giữ nguyên đường dẫn để duy trì kho dữ liệu cục bộ.
